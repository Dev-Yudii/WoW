# WoW

This repository contains my solutions, adaptations, and guided implementations of [Workout Wednesday](https://www.workout-wednesday.com/) challenges.

## What is Workout Wednesday?

Workout Wednesday is a weekly challenge focused on recreating data-driven visualizations. The challenges are designed to encourage participants to develop their skills in Tableau and Power BI.

New challenges are released every Wednesday, and participants are encouraged to recreate the proposed visualizations as closely as possible.

## How to navigate this repository

The repository is organized by year, month, and weekly challenge:

```text
WoW/
├── 2026/
│   ├── October/
│   │   ├── README.md
│   │   ├── WoW40.pbix
│   │   ├── WoW40.pdf
│   │   ├── WoW41.pbix
│   │   └── WoW41.pdf
│   └── November/
│       ├── README.md
│       ├── WoW44.pbix
│       └── WoW44.pdf
└── 2027/
    └── ...
```

- **Year/** — Groups challenges by year.
- **Year/Month/** — Contains a monthly README listing the challenges, their original authors, links to the original challenges, and brief notes on what I learned from each implementation.

Each challenge includes two file formats:
- **PDF** — A quick preview of the visualization. It may not capture the entire project, including interactive elements and animations.
- **PBIX** — The Power BI project file, providing access to the complete report and its interactive features.
